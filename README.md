# Coffee Shop Monitor Agent

An intelligent, real-time coffee shop monitoring agent built using the **Agent Development Kit (ADK)** and **Gemini**, designed to track daily inventory, monitor order queues, and optimize coffee shop operations.

---

## Features

- **Inventory Tracking**: Monitor stock levels for coffee beans, dairy, syrups, and supplies in real time.
- **Operational Insights**: Analyze peak hours, order throughput, and queue waiting times.
- **Natural Language Querying**: Ask questions about shop status, daily sales, or supply needs using plain English powered by Gemini.
- **ADK Native**: Standardized implementation using `google-adk` framework tooling.

---

## Prerequisites

- **Python**: 3.10 or higher
- **GCP Project**: A Google Cloud project with Vertex AI / Gemini API enabled.
- **Package Manager**: `uv` installed (`pip install uv`)
